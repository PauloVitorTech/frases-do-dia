# 💡 Inspiração Diária - Frases do Dia

Um site web interativo, leve e responsivo desenvolvido para gerar frases motivacionais e dicas sobre tecnologia e programação a cada clique. 

✨ **Mais de 100 frases exclusivas** para começar bem o dia!

---

## 🚀 Funcionalidades
- **Botão Interativo:** Sorteia uma nova frase a cada clique de forma inteligente (sem repetir a frase anterior).
- **Design Moderno (Dark Mode):** Interface limpa, com gradientes suaves e estilo futurista.
- **Animações Fluidas:** Transições suaves ao trocar as frases na tela.
- **Totalmente Responsivo:** Funciona perfeitamente em computadores, tablets e celulares.

---

## 🛠️ Tecnologias Utilizadas
Este projeto foi desenvolvido utilizando apenas as tecnologias nativas da web, sem necessidade de instalação de dependências ou frameworks complexos:
- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização avançada, Flexbox e animações.
- **JavaScript (Vanilla):** Lógica de manipulação do DOM e sorteio aleatório das frases.
